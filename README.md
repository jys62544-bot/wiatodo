# Today Todo

Today Todo 是一个轻量级 Windows 桌面待办小工具。它默认以一个小型圆形悬浮图标显示在桌面上，图标旁会显示实时 CPU 和内存占用；点击后展开为待办面板，也可以隐藏到系统托盘中，适合整理长期规划、短期执行事项和日常临时记录。

项目仓库名为 `wiatodo`。

## 主要功能

- 小型圆形桌面悬浮图标，圆形图标自身保持紧凑尺寸。
- 悬浮图标旁显示实时 CPU 与内存占用。
- 点击悬浮图标打开待办面板，默认展示长期待办。
- 悬浮图标未锁定时可以拖动。
- 悬浮图标右上角锁按钮可直接锁定或解锁位置。
- 锁定后悬浮图标不可拖动，避免误触移动。
- 待办面板固定在合适的桌面位置打开，不受悬浮图标当前位置影响。
- 待办面板标题栏支持手动拖动。
- 待办面板提供长期待办和短期待办两个独立列表，长期在左、短期在右。
- 支持添加、编辑、完成、取消完成、删除待办。
- 支持通过左侧拖动手柄手动排序，拖动时会显示半透明实时预览。
- 支持清空已完成事项，并带确认提示。
- 支持重要事项标记，重要事项会置顶并高亮。
- 已完成事项会变淡并显示删除线。
- 待办内容无论多长都会完整换行显示，不会省略。
- 支持批量导入多行待办。
- 批量导入可以直接导入，也可以先预览再导入。
- 本地持久化保存待办分组、手动排序、完成状态、重要状态、锁定状态、窗口位置和面板尺寸。
- 支持隐藏到 Windows 系统托盘。
- 托盘右键菜单支持显示待办、显示悬浮图标、锁定/解锁和退出程序。
- 双击托盘图标可直接唤起悬浮图标。
- Windows 安装包会嵌入 WebView2 bootstrapper，目标电脑缺少 WebView2 Runtime 时可在安装过程中补齐。

## 使用方式

1. 安装并启动 Today Todo。
2. 桌面上会出现一个圆形悬浮图标。
3. 查看图标旁的 CPU 和内存占用，点击右上角锁按钮可锁定或解锁悬浮窗。
4. 点击悬浮图标打开待办面板，默认进入长期待办列表。
5. 在长期待办或短期待办中添加单条待办，或使用“批量导入”一次添加多条。
6. 点击事项左侧按钮完成待办。
7. 点击编辑按钮可修改待办内容。
8. 按住事项左侧拖动手柄可手动调整顺序。
9. 点击星标按钮切换重要状态。
10. 点击面板右上角收起按钮返回悬浮图标。
11. 点击隐藏按钮可隐藏到系统托盘。
12. 双击系统托盘图标可恢复悬浮图标。
13. 右键系统托盘图标可打开更多操作菜单。

## 批量导入格式

批量导入会把每个非空行识别为一条待办，并自动去掉常见编号或项目符号前缀。

支持的格式示例：

```text
1、整理本周计划
2、阅读两篇技术文章
3、备份重要文件
4、购买生活用品
5、运动三十分钟
```

也支持这些前缀：

```text
1. 写项目总结
1) 检查邮件
- 清理桌面
* 更新软件
• 准备明天的任务清单
```

类似 `5.29 完成阶段复盘` 这样的日期文本会被保留，不会被错误识别为编号。

## 数据存储

Today Todo 使用本地持久化存储，不需要账号，也不会同步到云端。保存内容包括：

- 待办标题
- 待办所属分组
- 手动排序结果
- 待办完成状态
- 重要标记
- 创建、更新和完成时间
- 锁定状态
- 悬浮图标位置
- 面板尺寸

## 技术栈

- Tauri 2：Windows 桌面壳、无边框窗口、系统托盘和打包。
- React 18：前端界面。
- TypeScript：类型和业务逻辑。
- Tailwind CSS：浅色、紧凑的桌面工具样式。
- Vitest：单元测试。
- `@tauri-apps/plugin-store`：本地持久化存储。
- Lucide React：界面图标。
- Windows PDH 与内存状态接口：读取接近任务管理器口径的 CPU 和内存占用。

## 从源码运行

环境要求：

- Windows 10/11 x64
- Node.js 和 npm
- Rust 工具链
- Visual Studio Build Tools 或等价 MSVC 构建工具

安装依赖：

```powershell
npm install
```

启动前端开发服务器：

```powershell
npm run dev
```

启动 Tauri 桌面开发模式：

```powershell
npm run tauri dev
```

运行测试：

```powershell
npm test
```

构建前端：

```powershell
npm run build
```

打包 Windows 应用：

```powershell
npm run tauri build
```

## 安装包

打包成功后，Windows 安装包位于：

```text
src-tauri/target/release/bundle/nsis/Today Todo_0.1.1_x64-setup.exe
src-tauri/target/release/bundle/msi/Today Todo_0.1.1_x64_en-US.msi
```

推荐普通用户下载并运行 `Today Todo_0.1.1_x64-setup.exe`。

该应用目前未做代码签名，因此在其他电脑上安装时可能会出现 Windows SmartScreen 或“未知发布者”提示。选择继续运行后即可安装。

## 项目结构

```text
src/
  components/        React UI 组件
  services/          业务逻辑、导入解析、窗口服务、持久化服务
  store/             应用状态管理
  styles/            Tailwind 全局样式
  types/             类型定义
src-tauri/
  src/               Tauri/Rust 入口与系统托盘逻辑
  capabilities/      Tauri 权限配置
  icons/             应用图标
```
